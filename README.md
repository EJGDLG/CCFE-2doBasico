# CCFE - 2do Básico - Cuarta Unidad

Este repositorio centraliza las actividades correspondientes a la **Tercera Unidad** del ciclo escolar para los estudiantes de **Segundo Básico**.

Aquí se organizarán las tareas, ejercicios, hojas de trabajo y material de apoyo de las áreas de:

- 💻 Computación
- 🌐 Programación
- 🤖 Robótica

El objetivo es que los estudiantes desarrollen habilidades de comunicación escrita, comprendan los fundamentos de las redes informáticas y apliquen conceptos básicos de física relacionados con la robótica.

# 📚 Instructivo General del Curso – 2do Básico

## Contenido de la Tercera Unidad

Durante esta unidad se trabajarán tres áreas principales:

- **Computación:** Elaboración de ensayos.
- **Programación:** Redes básicas para introducir el desarrollo web.
- **Robótica:** Movimiento Rectilíneo Uniformemente Variado (MRUV) aplicado a la robótica.

Cada área tendrá una modalidad de trabajo diferente.

---

# 💻 1. Computación

## Modalidad

Durante esta unidad los estudiantes aprenderán la estructura y elaboración de un ensayo.

Las actividades podrán realizarse **a mano o en computadora**, dependiendo de las instrucciones proporcionadas por el docente.

## Contenidos

- ¿Qué es un ensayo?
- Partes de un ensayo.
- Organización de ideas.
- Redacción de un ensayo.
- Uso correcto de la ortografía y la puntuación.

## Indicaciones

- Leer cuidadosamente cada actividad.
- Redactar con sus propias palabras.
- Mantener buena ortografía y presentación.
- Seguir la estructura correcta del ensayo.
- Respetar la modalidad indicada por el docente.

## Se evaluará

- Comprensión del tema.
- Organización de ideas.
- Ortografía.
- Redacción.
- Presentación.
- Cumplimiento de instrucciones.

---

# 🌐 2. Programación

## Modalidad

En esta unidad se estudiarán los conceptos fundamentales de redes que servirán como base para el desarrollo web.

Las actividades se desarrollarán **durante los períodos de clase**.

## Contenidos

- Diferencia entre Internet y la Web.
- Historia del Internet.
- Dominio.
- Servidor.
- Hosting.
- Dirección IP.
- DNS.
- Navegadores web.
- Funcionamiento de una página web.

## Indicaciones

- Participar activamente durante las explicaciones.
- Resolver los ejercicios propuestos.
- Elaborar esquemas y dibujos cuando sean solicitados.
- Relacionar cada concepto con aplicaciones reales del desarrollo web.

## Se evaluará

- Comprensión de los conceptos.
- Participación en clase.
- Desarrollo correcto de los ejercicios.
- Análisis y razonamiento.

---

# 🤖 3. Robótica

## Modalidad

Durante esta unidad se trabajará el tema de **Movimiento Rectilíneo Uniformemente Variado (MRUV)** aplicado a situaciones reales de robótica.

Las actividades se desarrollarán **durante los períodos de clase** y deberán resolverse **a mano en hojas oficio**, salvo indicación diferente del docente.

## Contenidos

- Conceptos básicos del MRUV.
- Variables del movimiento.
- Fórmulas principales.
- Conversión de unidades.
- Aplicaciones del MRUV en robótica.
- Resolución de problemas.

## Indicaciones

- Resolver cada ejercicio mostrando el procedimiento.
- Utilizar correctamente las fórmulas.
- Colocar las unidades en cada resultado.
- Mantener orden y limpieza.
- Relacionar los ejercicios con situaciones reales de robótica.

## Se evaluará

- Identificación correcta de las variables.
- Uso adecuado de las fórmulas.
- Procedimiento completo.
- Resultados correctos.
- Presentación del trabajo.

---

# 📋 Reglas Generales de la Unidad

- Cumplir con las fechas establecidas por el docente.
- Leer cuidadosamente las instrucciones de cada actividad.
- Presentar los trabajos con orden y limpieza.
- No copiar trabajos de otros compañeros.
- Colocar nombre completo, grado, sección y fecha en cada actividad.
- Resolver todos los ejercicios mostrando el procedimiento cuando sea necesario.
- Consultar al docente en caso de dudas.
